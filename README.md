# 📱 Miraj Telecom

A complete customer management system for Miraj Telecom mobile service shop.

## Features
- Customer login/signup
- Admin panel (add/delete vouchers)
- Voucher search by slip number
- Customer's own product list
- Mobile friendly design

## Tech Stack
- HTML, CSS, JavaScript
- LocalStorage for data storage
- GitHub Pages for hosting

## How to Use
1. Customer: Create account and login
2. Admin: Username: `miraj`, Password: `admin123`
3. Admin can add vouchers
4. Customer can search vouchers and see own products

## Default Admin Login
- Username: `miraj`
- Password: `admin123`
